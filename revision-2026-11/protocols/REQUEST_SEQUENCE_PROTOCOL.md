# Multi-target and sequential request protocol v1

Frozen before sequence runs, 2026-11-11. Responds to R1's multi-target and
repeated-request recommendation; does not establish large-client scalability.

CIFAR-10/ResNet18, ten clients, IID and alpha0.5, seeds42–44. Same canonical
training/event/evaluation budgets and source hashes as the original core.
For each seed/partition compare simultaneous {0,1} versus sequential {0} then
{1} for Fed-EMNU, UNSIR-style, FT and GA. Use existing core original, class0
reference and first-event outputs; second event has each method's own first
output as its parent. Thus matching starts apply within simultaneous comparison
and within the original first event; second-event parent weights differ across
methods as part of their serial paths. Never imply identical second-event starts.

Fresh retained-data reference excludes {0,1} at all clients and uses original
partition/schedule and independent initialization seed1000+seed for 50rounds,
five local epochs. Same cumulative reference serves both final paths. Six new
references plus 48 approximate events =54 formal stages. First-event core
measurements remain n3 subset and excluded from five-seed population mixing.

Wrapper separates cumulative labels (evaluation/reference/quarantine) from
new current labels (noise, participation, GA access). Previously revoked
examples cannot enter retained impair/repair. First {0} stage precedes {1};
order fixed in advance. Simultaneous targets processed 0 then1 using the
canonical mechanism. No unavailable-client changes or all-client aggregation
variant. Sparse-owner participation limitation remains disclosed.

Use identical historical-member splits across paths, target macro over {0,1},
retained macro over eight classes; save class-specific FA/RA and attack metrics,
especially class0 rebound after event2. Final TV/disagreement is against the
same cumulative reference. For class0 rebound compare individual-class
before/after accuracy from event2 parent/final predictions. Report per-event
time/steps/payload plus sequential first+second totals. Native total budgets
differ; not an equal-compute ablation. No repeated-FL relearning claim follows.

Pilot separate: seeds42 only, both partitions, 1000train/500test, one FLround/
one local epoch. All methods/paths and cumulative reference must finish, then
audit cumulative IDs, actual parent/reference hashes, predictions and attack
splits before formal launch. No pilot metric in scientific tables. No test-based
tuning or selective omission of poor outcomes. Formal/pilot hashes frozen in
their manifest; canonical runner/evaluator unchanged.
